# Projects

This directory records substantial practical projects used to turn OSSU concepts into working knowledge.

## Purpose

Projects should demonstrate understanding through implementation, design, testing and documentation rather than simply listing completed coursework.

## Project Categories

- [Programming](programming/README.md)
- [Algorithms](algorithms/README.md)
- [Systems](systems/README.md)
- [Networking](networking/README.md)
- [Databases](databases/README.md)
- [Security](security/README.md)
- [Machine Learning](machine-learning/README.md)
- [AI](ai/README.md)

## Project Record

Each substantial project should document:

1. Problem and objectives
2. Related OSSU course(s)
3. Concepts applied
4. Technologies used
5. Design and implementation
6. Testing and validation
7. Results
8. Lessons learned
9. Related books and papers
10. Future improvements

Projects should only be marked complete after the implementation and documentation are actually finished.

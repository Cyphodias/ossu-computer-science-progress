# Ventoy Portable Laboratory

The Ventoy USB is a portable operating-system laboratory for booting and practising with multiple operating systems from one removable device.

## Purpose

- Test Linux distributions
- Practise installation and system administration
- Experiment with security-focused distributions
- Troubleshoot boot and storage problems
- Maintain portable recovery and diagnostic environments

## Operating-System Collection

The collection can include, as appropriate:

- Ubuntu
- Kali Linux
- Debian
- Other Linux distributions used for specific coursework or experiments
- Windows installation/recovery media where appropriate

The exact ISO inventory should be maintained in `iso-inventory.md` and updated whenever an image is added or removed.

## Concepts to Document

- Ventoy installation and updates
- UEFI boot
- Secure Boot considerations
- ISO management
- Persistence where supported
- Partition layout
- Checksum verification
- Portable troubleshooting workflow

## Safety

Only use security-testing distributions and tools against systems and networks that I own or am explicitly authorized to test.

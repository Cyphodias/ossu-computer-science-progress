# End-State Capabilities

The research track is successful when the following capabilities have been developed. These are capability targets, not merely reading targets.

| Area | End-State Capability |
|---|---|
| **Mathematics** | Be able to read ML derivations involving vectors, matrices, gradients, probability, expectations, optimization and information theory. |
| **Algorithms** | Analyze complexity and implement classical algorithms rather than treating libraries as black boxes. |
| **Systems** | Understand how CPUs, memory, operating systems, networks and distributed systems interact. |
| **Theory** | Understand computability, complexity, formal reasoning and the limits of computation. |
| **Security** | Understand cryptographic primitives, threat models, secure systems and adversarial ML. |
| **Machine Learning** | Derive, implement and evaluate classical machine-learning methods. |
| **Deep Learning** | Implement and reason about neural networks, optimization, regularization and representation learning. |
| **NLP & Transformers** | Explain the progression from language models and sequence models through attention, Transformers and modern LLMs. |
| **Computer Vision** | Understand and implement modern visual representation, detection, segmentation and generative methods. |
| **Reinforcement Learning** | Understand value-based, policy-based and actor-critic methods and their deep-learning extensions. |
| **AI Systems** | Understand the systems constraints behind training, serving, scaling, memory efficiency and distributed AI. |
| **Research** | Read, reproduce, critique and extend technical research papers and communicate results clearly. |

# Experiments

This directory records practical laboratory experiments used to reinforce Computer Science concepts.

## Areas

- Linux and operating systems
- Virtualization
- Networking
- Security
- Distributed systems
- AI and Machine Learning

## Experiment Record

Each experiment should document:

1. Objective
2. Related OSSU course or research topic
3. Prerequisites
4. Environment
5. Procedure
6. Observations
7. Results
8. Problems encountered
9. Lessons learned
10. Related project, book or paper

Experiments should be reproducible where practical and must not expose private infrastructure information.
